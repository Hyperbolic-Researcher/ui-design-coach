# ui-design-coach · AI UI 设计教练

一个对话式 Skill：不直接替你画界面，而是分步引导你把「AI 做出来的界面都很像」这件事拆开解决，最终交给你一段打磨过的 UI 提示词。

方法论来自 Anshu Chimala 的文章 [How to turn your AI into a world-class designer](https://www.lennysnewsletter.com/p/how-to-turn-your-ai-into-a-world)（Lenny's Newsletter，2026-09-01，双钻模型改造的三阶段八手法）。本 Skill 在其前增加两步需求澄清，并把整个流程做成一次只推进一步、每步校验的教练式对话。

## 解决的问题

LLM 是 next-token 预测器，每个设计决策都选「最安全、最不得罪人」的答案，于是所有 AI 生成的界面收敛到同一套：蓝紫渐变、圆角卡片、左文右图、通用图标。这不是模型不够强，是提示词把它推回了舒适区。

## 八个阶段

| 阶段 | 做什么 | 来源 |
|---|---|---|
| 1 | 发散找问题：谁用、什么场景、遇到什么麻烦 | 教练扩展 |
| 2 | 聚焦核心问题：收敛到唯一 1 条 | 教练扩展 |
| 3 | 发散解法方向：3 个气质不同、具体可感的方向 | Discover |
| 4 | 锁定方向，写发散提示词；卡壳时注入真随机种子 | Discover |
| 5 | 无历史包袱的独立评审，9/10 门槛由教练持有 | Define |
| 6 | 素材补强：图片、着色器、循环动效、状态过渡 | Define |
| 7 | 减法修剪：按意图判断，不按样式种类一刀切 | Deliver |
| 8 | 人工重写关键文案，输出定稿提示词 | Deliver |

## 设计取舍

- **方向先于细节，但具体不是敌人**：拦截的是「做个好看的页面」这种空泛指令，不是具体风格参照。用户提前给的细节不丢弃，记入「细节暂存」，到阶段 4、6 再启用。
- **种子串是补药，不是主食**：先跑基线提示词，出现「几版还是同一个骨架」才抽一颗真随机种子。一次一颗，多颗互相稀释。
- **门槛不进评审 prompt**：9/10 由教练侧判定，写进评审提示词会污染打分客观性。评审循环最多 3 轮，防止无限空转。
- **减法按意图判断，不按样式种类一刀切**：渐变、发光、卡片本身不是罪，模板感来自没有理由的选择和缺失的层级。
- **文案不外包**：模型只出候选，标题、按钮、空状态、错误提示由人定稿——那是 AI 味最后藏身的地方。
- **小修不启动流程**：改圆角、换配色、调间距直接处理，不套八阶段。

## 安装

复制到 WorkBuddy 用户级 skill 目录：

```text
~/.workbuddy/skills/ui-design-coach/
```

需要 `SKILL.md` 与 `scripts/seed_string.py` 保持相对位置，阶段 4 会调用该脚本。

## 使用

```text
帮我写 UI 提示词，我要做一个面向独立开发者的产品落地页，现在 AI 做出来都是蓝紫渐变那种。
```

教练会从「这个 UI 给谁用、用户遇到什么麻烦」开始，一次问一步。

## 种子脚本

```sh
python scripts/seed_string.py              # 一颗 64 位种子
python scripts/seed_string.py --count 2 --length 96
```

只用 Python 标准库（`secrets`），不联网、不读写文件、不访问环境变量。数量限 1—32，长度限 8—512，越界返回退出码 2。

## 不做什么

- 不直接生成界面，也不改你的代码
- 不替用户决定审美方向，方向和品味必须由用户带进来
- 不追求「达到某个审美分数」，评分只用于观察改进
